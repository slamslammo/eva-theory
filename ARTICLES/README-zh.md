# Articles

`eva-theory` 的面向读者文章。

English: [README.md](README.md)

本目录保存面向公众的解释性文章，用不同深度解释 EVA。这些文件不替代 `THEORY/` 中的主理论文档，而是提供进入理论的阅读入口。

## 本目录文件

- `01-paradigm-introduction.md` — 关于 existence-centered paradigm 的入门文章，解释它与 task-centered agent design 的区别
- `01-paradigm-introduction-zh.md` — 上述文章的中文版本
- `02-architectural-contributions.md` — 聚焦 EVA 四个主要架构区别的工程向文章
- `02-architectural-contributions-zh.md` — 上述文章的中文版本
- `03-related-work-and-positioning.md` — 将 EVA 放在相邻 agent 范式、认知传统和 safety/control work 中定位的说明
- `03-related-work-and-positioning-zh.md` — 上述说明的中文版本
- `04-v0.6-extension.md` — 面向读者解释 v0.6 相对 v0.5 core 增加了什么
- `04-v0.6-extension-zh.md` — 上述文章的中文版本

## 建议阅读顺序

2. `02-architectural-contributions-zh.md`
3. `03-related-work-and-positioning-zh.md`
